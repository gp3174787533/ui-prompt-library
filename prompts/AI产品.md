# AI产品

## AI 聊天助手界面 (`ai-chat-app`)

- 风格：极简 / 对话 / 浅色
- 场景：AI 聊天/智能助手产品界面
- 适用工具：v0、Lovable、Cursor

**EN prompt（复制用）**

```
Design an AI chat assistant interface: centered conversation column (max-width 760px), clean message bubbles with the assistant's answers in plain text blocks, suggestion chips above the input, a floating rounded input box with attach and send buttons, left sidebar with chat history, subtle typing indicator, light theme with one violet accent, calm and focused like ChatGPT/Claude, no clutter.
```

**中文说明**：AI 聊天界面：居中对话列、建议 chips、悬浮圆角输入框、左侧历史列表、紫色点缀，ChatGPT/Claude 式 calm 极简。

## AI 绘图工具界面 (`ai-image-tool`)

- 风格：深色 / 画布 / 工具栏
- 场景：AI 图片生成/编辑工具
- 适用工具：v0、Cursor

**EN prompt（复制用）**

```
Create an AI image generation tool UI: dark editor theme, large central canvas with the generated image, left toolbar (generate, inpaint, upscale, variations), right panel with prompt textarea, model selector, aspect-ratio and style preset chips, bottom filmstrip of generation history, purple-blue accent glow on the primary Generate button, professional creative-tool feel like Midjourney/Leonardo.
```

**中文说明**：AI 绘图工具：深色编辑器、中央大画布、左工具栏、右提示词+模型+比例+风格面板、底部历史胶片条，生成按钮紫蓝光效。
