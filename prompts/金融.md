# 金融

## 网上银行/金融门户 (`banking-web`)

- 风格：稳重 / 浅色 / 信任感
- 场景：银行/证券 Web 门户首页
- 适用工具：v0、Qoder

**EN prompt（复制用）**

```
Design a trustworthy online banking web homepage: white and deep-green palette, top navigation with login panel, account overview cards, transfer and payment quick entries, exchange-rate and product tables, security notice area, clear large clickable targets, conservative typography, no trendy gradients — stability and clarity above all.
```

**中文说明**：金融门户：白+深绿、登录区、账户总览卡、转账快捷入口、汇率/产品表格、安全提示，稳重清晰第一。
