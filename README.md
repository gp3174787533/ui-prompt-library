# AI 生成 UI 创意提示词库

给 AI 生成 UI（v0 / Lovable / Cursor / Qoder / 即梦 / Midjourney 等）用的提示词库。
由 Muse 用 `ui-prompt-library` Skill 维护，peng 在「AI生成UI创意提示词」空间里浏览、复制、收藏。

## 结构

- `prompts.json` — 全库机器可读数据（Skill 和空间的数据源）：id、标题、分类、风格标签、场景、英文提示词（复制用）、中文说明、适用工具
- `prompts/<分类>.md` — 按分类的人读版，每个分类一个文件
- `favorites.json` — 收藏清单（id 数组）。**选设计时收藏优先**
- `inbox.md` — 自动收集的待整理区：新收集的提示词先落这里，整理（去重、定分类、补中文说明）后才进 `prompts.json`

## 分类（9 类，33 条（首版 18 条 + 细节优化同类收集 10 条 + 费纸张原作版 5 条））

SaaS后台 / 移动端App / 落地页官网 / 电商零售 / 数据大屏 / AI产品 / 金融 / 内容社交

## 维护规则

1. 新增提示词必须有：唯一 id（英文短横线）、分类、至少 1 个风格标签、场景、英文提示词、中文说明。
2. 入库前先查 `prompts.json` 去重：同一场景+同一风格只保留一条，变体在原条目里注明。
3. 每次改库都 git commit，信息写清加了/改了哪条（如 `add: mobile-fintech 移动端金融App`）。
4. 收藏只增删 `favorites.json`，不动提示词正文。
5. 做 UI 设计选提示词的顺序：先按场景/分类匹配 → 收藏的排最前 → 再按风格标签匹配度排序。

## 自动收集

来源：peng 分享的链接/截图/原文、Muse 做 UI 任务时沉淀的好提示词、公开渠道看到的高质量 UI 提示词。
流程：先进 `inbox.md`（标来源和日期）→ 按上面规则整理 → 进 `prompts.json` + 对应分类 md → git commit。
不直接把未整理的原文塞进正式库。
